# Decision Records

A decision record is a short note that explains one key choice and the cost of undoing it.

## Format

- Name the file `NNNN-short-title.md` and copy `0000-template.md`.
- Never reuse a number.
- Use one status: `accepted`, `proposed` or `superseded`.
- Record one decision per file and keep it under about 25 lines.
- Supersede a record with a new one instead of editing history. Change the old status to `superseded` and name the new record.
- Add a row to the table below in the same change.
