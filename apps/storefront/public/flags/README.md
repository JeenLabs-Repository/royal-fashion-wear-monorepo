Vendored from https://github.com/lipis/flag-icons (MIT), tag v7.5.0, flags/4x3.

This folder holds India's flag only (`in.svg`). `<CountryFlag>` falls back to the
pinned jsDelivr URL for any other country code, so a region added later works
without touching this directory. To keep the request same-origin, drop the
matching `<code>.svg` in here.
